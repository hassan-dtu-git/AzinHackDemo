# ResearchPilot AI

Ask a research question. Get an evidence-backed report.

ResearchPilot AI is a hackathon MVP concept by Team ByteForge for AzinHack. The application is being built to plan research queries, discover public sources, extract structured evidence, compare claims, assess candidate research gaps, and present a cited report with an evidence graph.

> Current status: project scaffold and implementation are in progress. Do not treat the product description as a claim that all features are already implemented.

## Planned stack

- Frontend: React, Vite, TypeScript
- Backend: Python, FastAPI, Pydantic, HTTPX
- Storage: SQLite for the MVP
- Research discovery: TinyFish, subject to verification of the current API contract and team credentials
